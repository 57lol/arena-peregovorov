# Вычитка интерфейса «Переговорки»

166 правок по изменённым строкам с текстом в 36 файлах интерфейса и контента (импорты не считаются). Согласованно обновлены ожидания в трёх тестовых файлах и семь записей фикстуры ударений. Игровая логика не менялась; `g` и `plural` используются только для оформления текста.

Проверены экраны игрока и жюри, обучение, подсказки, разбор, сюжетные переходы, финалы, лаборатория и `index.html`. В `public` HTML-файлов нет. Запрещённые файлы и `src/content/scenarios/**` не затронуты.

Заметные примеры «было → стало»:

1. «HR „Алабуги“, наставник новеньких» → «Сотрудница отдела кадров „Алабуги“, наставница новеньких».
2. О Дарине: «Лучший кандидат … ждёт финала» → «Лучшая кандидатка … ждёт заключительного собеседования».
3. Для персонажей-женщин: «Голос собеседника» → «Голос собеседницы»; аналогично исправлены подписи в аналитике и подсказках.
4. «Провести встреча» → «Провести встречу».
5. «Ждём ответ» → «Ждём ответа».
6. «Видно только итог» → «Виден только итог».
7. В карточке участника: «1 из 1 реплик» → «1 из 1 реплики» через `plural`; также исправлены формы «1 очко / 2 очка / 5 очков».
8. «Отвечает …, сделка на месте» → «Отвечает …, условия прежние»: предложение ещё не является сделкой.
9. «Катсцены» → «Ролики», «Титул» → «Главный экран», «Заполнить бриф» → «Заполнить описание».
10. «Проговорить все часы встречи» → «Проговорить всю встречу».
11. «Оно было лучше интегратора» → «Её условия были выгоднее, чем услуги интегратора».
12. «Производственный слот» → «Место в производственном графике».
13. «Emre called himself» → «Emre called you directly».
14. «Why is … so important for you?» → «Why is … so important to you?».
15. «6000 ₽», «90%» → «6 000 ₽», «90 %» с неразрывными пробелами; вложенные русские кавычки оформлены как «…„…“…».

Счётчики ходов, реплик, очков и исходов проверены: изменяемые числительные согласуются через `plural`, включая формы после «из». Женский род проверен для Ларисы Петровны, Дарины и Розы. Подпись первой звезды уточнена: «сделка не хуже запасного варианта» соответствует условию `>=`.
