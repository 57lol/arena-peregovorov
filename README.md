# Переговорка

Тренажёр переговоров для сотрудников закупок, продаж и найма.
Игрок договаривается с персонажем, затем видит результат и разбор своих фраз.
HR и руководитель дают команде одно дело по ссылке и следят за встречами на общей доске.
Финал ЛЦТ 2026, кейс №9 ОЭЗ «Алабуга».

## Как попробовать

[Открыть игру](https://arena-peregovorov.ru). Ключ жюри — в материалах сдачи: откройте выданную ссылку с `?key=…`. Сам ключ в репозитории не публикуем. Кнопка «Для жюри» или `/?jury` ведёт к четырём шагам: настроить дело → провести встречу → посмотреть разбор → открыть кабинет руководителя. `?jury` сам по себе доступ не выдаёт.

По умолчанию отвечают голосом: разрешите микрофон. Текстовый ввод выбирается в настройках; для проверки есть `?text`. Встреча проходит в 3D, при недоступном WebGL есть запасной 2D-вид. После неё — очки, доверие, карта сделок и переигровка с выбранного хода.

## Локальный запуск

Node.js 22. Настройки и пояснения — в [.env.example](.env.example); для моделей и речи скопируйте его в `.env` и заполните нужные ключи. По умолчанию там `LLM_PROVIDER=offline`. С ключами Яндекса и AITunnel разметка и реплики идут через Claude, Яндекс — запасной; `KIT=base` оставляет только YandexGPT и SpeechKit.

```sh
npm ci
npm run dev          # http://localhost:5173, API :8787
npm run dev:offline  # явно без LLM; речь отключается отдельно: SPEECH=off
npm test
npm run lint
npx tsc -b
```

Сборка и запуск одним сервером:

```sh
npm run build
npm run build:server
npm start            # http://localhost:8787
```

Без `GATE_SECRET` продакшен-сервер предупреждает в журнале и оставляет сайт открытым. Для закрытого демо задайте секрет и способ входа (`JURY_KEY` или `JURY_KEYS`). Без внешних ключей движок работает на правилах и заготовках; для работы без микрофона выберите текст в настройках.

В `JURY_KEYS` сервер пропускает битые записи с предупреждением без ключей; при повторе имени или ключа использует первую корректную пару. Личный ключ, совпадающий с общим `JURY_KEY`, пропускается; общий вход сохраняется. Если старый `ADMIN_KEY` использовался в URL (`?admin=`), замените его: теперь он даёт доступ к статистике судей через `Authorization: Bearer`. Для итогов `/golosa` задайте новый независимый `VOTE_ADMIN_KEY` и вводите его в форме без `?admin=`.

```sh
docker build -t peregovorka .
docker run --rm -p 8080:8080 --env-file .env -v peregovorka-data:/data peregovorka
```

В Docker ворота настраиваются теми же переменными. Том `/data` сохраняет кэш, комнаты и счёт расходов между запусками.

## Дела

В коде **9 исходных дел**: семь русскоязычных, одно английское и одно с китайским поставщиком. Это не «8 + английское + китаец»; жёсткие версии не считаем отдельными историями.

| ID для `?case=` | Дело |
|---|---|
| `offer` | Оффер для робототехника |
| `tara` | Тара к запуску |
| `client` | Удержать клиента |
| `dorm` | Сосед по комнате |
| `stop` | Остановка у ларька |
| `shop` | Чайник без чека |
| `launch` | Ночь перед запуском |
| `istanbul` | The Istanbul Line — разговор на английском, разбор по-русски |
| `china` | Поставщик из Шэньчжэня — Ли Вэй, разговор по-русски, допродажи |

Первые три и четыре бытовых дела составляют семь глав «Новенького». В сюжете главы идут по порядку; в хабе жюри доступны сразу. Суффикс `-hard` открывает жёсткую версию библиотечного дела. Встреча рассчитана на 10–12 ходов; в деле 4–5 пунктов договора и восемь возможных финалов. Форма «Своё дело» собирает новый сценарий и проверяет его таблицы.

## Архитектура

- React и Three.js показывают встречу; Hono на Node.js обслуживает API и собранный фронт.
- Движок `src/engine` считает уступки, доверие, соглашение, очки и финал по скрытым таблицам сторон.
- Разметчик выделяет предложение и 22 поведенческих индикатора с цитатами; правила проверяют результат.
- Разметка и реплики — Claude Sonnet 5.5 через AITunnel. Разметку страхуют YandexGPT 5.1 Pro и правила, реплику — YandexGPT и заготовка.
- Базовая комплектация — полностью российский контур: YandexGPT 5.1 Pro + SpeechKit, включается одной настройкой `KIT=base`.
- Сервер проверяет условия, согласие, числа и раскрытие тайн; неудачная проверка ведёт к переписке и запасному ответу.
- Разметка и реплика могут считаться параллельно; ранняя реплика используется только при совпадении рамки.
- Озвучка: ElevenLabs → SpeechKit; вступления записаны заранее, для китайского персонажа есть отдельные записи.
- Распознавание: потоковый Scribe при настроенном воркере, иначе Яндекс; сбои потока страхует Яндекс.
- Файловый кэш хранит разметку, реплики, звук и свои дела; комнаты и расход лежат в `CACHE_DIR`.
- Живая доска получает состояние встреч, итог сервер пересчитывает из истории; переписка доступна с согласия игрока.
- Общий бюджет и квоты проверяются перед платными вызовами, расходы записываются по провайдеру и пропуску.

SPIN-вопросы о последствиях и выгоде опираются на данные разработчика Huthwaite; независимая рецензированная проверка здесь не подтверждена. Индивидуальных численных норм для них нет.

## Параметры адреса

Параметры соединяются через `&`. Некоторые режимы запоминаются во вкладке, даже когда игра очищает адрес.

| Параметр | Что делает |
|---|---|
| `?key=…` | Вход по общему или личному ключу жюри; сервер выдаёт cookie и убирает ключ из адреса |
| `?jury` | Сразу хаб жюри |
| `?reset` | Стирает прогресс, настройки и сохранённые ссылки игры в этом браузере, очищает sessionStorage вкладки; серверные комнаты остаются |
| `?case=tara` | Дело по ID, включая `-hard` и сохранённые `gen-…`; запасная ссылка без сервера — `#case=…` |
| `?voiceonly`, `?text` | Принудительно голосовой или текстовый ввод до закрытия вкладки; `=off` снимает принуждение |
| `?stt=scribe`, `?stt=off` | Scribe принудительно или только Яндекс; другое значение возвращает автовыбор. `off` не отключает микрофон |
| `?tts=eleven`, `?tts=off` | Включает или снимает тест ElevenLabs во вкладке. `off` не отключает основной голос сервера |
| `?llm=…` | Выбирает модель реплики из серверного списка `VOICE_LLM_ALLOWED`; при `LAB=off` недоступно |
| `?room=…` | Присоединяет участника к тренировке, обычно вместе с `case` |
| `?board=…&key=…` | Доска руководителя; здесь `key` — секрет доски, а не ключ жюри |
| `?perf` | Диагностика производительности |
| `?lab`, `?voices` | Лаборатория моделей или голосов; серверные вызовы зависят от `LAB` |
| `?tutorial=1` | Включает обучение в автоматическом браузерном прогоне |
| `?cutscenes=1` | Включает катсцены в автоматическом прогоне |
| `?cutscene=prologue&t=12` | Открывает катсцену; необязательный `t` останавливает её на заданной секунде |
| `?world=…` | Витрина 3D: `factory`, `office`, `dorm`, `street`, `shop`, `bytovka`, `inei` |
| `&yaw=…&pitch=…&desk=1&xray=1&face=…` | Только витрина: угол головы в градусах, взгляд на стол, рентген, лицо; `case` задаёт её дело |

Ссылку на доску хранит руководитель. Она открывает результаты всей группы; вход на закрытый сайт всё равно нужен.

## Тесты

`npm test` — движок, разметка, проверка реплик, API, бюджет, пропуска, комнаты и клиентская логика. `node --import tsx scripts/check-scenarios.ts` пересчитывает таблицы всех дел без платных запросов.

Сквозные проверки лежат в `scripts/*e2e*.ts`: `e2e-game.ts` — партия, `story-e2e.ts` — сюжет, `board-e2e.ts` и `live-room-e2e.ts` — команда и живая доска; `modes-e2e.ts`, `stt-e2e.ts`, `mic-e2e.ts`, `eleven-e2e.ts` — ввод и речь. Запуск и флаги описаны в начале каждого файла. Например, после `npm run dev:offline`:

```sh
npx playwright install webkit chromium
node --import tsx scripts/e2e-game.ts --url http://localhost:5173 --only tara
```

Проверки с живыми провайдерами тратят деньги; для них читайте условия `--live` в скрипте. Некоторые прогоны сохраняют снимки в `~/Arena-materials`.

## Лимиты и защита денег

Общий расчётный бюджет — 6000 ₽ по умолчанию (`LLM_TOTAL_RUB`). С 80% Яндекс переходит на запасную модель, кроме запросов, которым явно нужен Pro. При исчерпании бюджета новые платные вызовы блокируются. Суточный рублёвый лимит задаётся отдельно; по умолчанию его нет. Это внутренний учёт, а не лимит в кабинете провайдера: параллельные запросы и расчётные цены могут дать расхождение со счётом.

По умолчанию: 20 платных ходов в минуту на вход, 20 генераций дела в сутки, 60 синтезов ElevenLabs в час, 300 в сутки на пропуск и 20 000 символов на сервер в сутки; Scribe — 120 потоков в час и 300 в сутки. Для проверенных пропусков квоты персональные, общий потолок IP — ×10; адрес прокси доверенный только из `TRUSTED_PROXIES`. Все настройки — в [.env.example](.env.example).

ElevenLabs озвучивает только разрешённые сервером тексты, повторный звук берётся из кэша. Есть таймауты, очередь синтеза и временное отключение провайдера после повторных сбоев. Scribe резервирует секунды до подключения; попытки Яндекса учитываются, включая хедж и отмену. Ключи провайдеров остаются на сервере или в воркере.

## Если нейросеть недоступна

Разметку выполняют правила, персонаж отвечает заготовками, результат и разбор по-прежнему считает движок. Новое дело заменяется ближайшим из библиотеки с выбранным характером и сложностью. При отказе ElevenLabs пробуем SpeechKit; если речь недоступна, переключитесь на текст в настройках.

Без API игра может продолжаться в браузере, но создание серверной комнаты, живая доска и отправка результатов недоступны. Это запасной режим с более простым пониманием свободной речи.
