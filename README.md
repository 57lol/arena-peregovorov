# Переговорка

Игра-тренажёр переговоров для закупок, продаж и найма. Игрок договаривается с персонажем, получает разбор своих фраз и может переиграть трудный ход. Руководитель даёт команде одно дело по ссылке и видит результаты на общей доске.

Финал ЛЦТ 2026 · кейс №9 ОЭЗ «Алабуга». Ссылка на демонстрацию и ключ жюри — в материалах сдачи. `/?jury` открывает маршрут проверки: своё дело → встреча → разбор → кабинет. Сам параметр доступ на закрытый сайт не выдаёт.

## Как проверить без ключей

1. Установите Node.js 22 и зависимости: `npm ci`. Версии зафиксированы в `package-lock.json`; для первой установки нужен доступ к npm или заранее заполненный npm-кэш.
2. В чистой копии проекта без `.env` запустите `npm run dev:offline`. Ключи внешних сервисов не нужны.
3. Откройте `http://localhost:5173/?jury&text`, выберите дело, проведите встречу и откройте разбор. Без ключей работают правила и заготовки; микрофон и живой синтез недоступны.
4. Для проверки сборок и тестов выполните `npm run build`, `npm run build:server`, `npx vitest run`. Эти команды не поднимают игровой сервер.

Если `.env` уже настроен, `dev:offline` отключает только модели: для речи задайте `SPEECH=off`, а `KIT=base` уберите — он принудительно включает Яндекс. Офлайн-режим не требует интернета после установки зависимостей. Локальный API продолжает обслуживать кабинет и доску; без самого API остаётся только одиночная игра в браузере.

## Запуск и настройки

```sh
npm ci
npm run dev          # Vite :5173 + API :8787, для разработки
npm run dev:offline  # то же, модели отключены
npm run build        # TypeScript + фронт в dist/
npm run build:server # сервер в dist-server/server.mjs
npm start            # один production-сервер на :8787
```

Перед `npm start` задайте в окружении или `.env` **`GATE_SECRET`** и способ входа: `JURY_KEY`, `JURY_KEYS` либо пару `SITE_LOGIN` + `SITE_PASSWORD_HASH`. Без непустого `GATE_SECRET` production не стартует; один секрет подписи ещё не даёт пользователю способ войти. В режиме разработки ворота не подключены. `PORT` меняет порт API; при разработке передавайте его также процессу Vite.

[.env.example](.env.example) можно скопировать в `.env`. Там безопасный старт: `LLM_PROVIDER=offline`. Одного добавления ключей недостаточно, чтобы включить модели.

| Что включить | Переменные |
|---|---|
| Яндекс: модели и запасной путь | `LLM_PROVIDER=yandex`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` |
| Sonnet для разметки и реплик, Яндекс в запасе | Настройки Яндекса выше + `AITUNNEL_API_KEY`; модели по задачам выбираются автоматически |
| Только Яндекс для моделей, голоса и распознавания | `KIT=base` + ключ и folder ID Яндекса; отключает AITunnel, ElevenLabs и Scribe |
| Голос ElevenLabs через внешний воркер | `TTS_PROVIDER=elevenlabs`, `ELEVEN_RELAY_URL`, `ELEVEN_RELAY_SECRET`; ключ ElevenLabs хранится у воркера |
| Scribe Realtime | Тот же воркер; для публичного HTTPS-сайта за прокси задайте точный `STT_ORIGIN` |
| Отключить речь / отключить только Scribe | `SPEECH=off` / `STT_STREAM=off` (во втором случае остаётся Яндекс) |

Без ключей основной модели сервер переходит на правила. При сбое модели есть запасной путь, результат сделки всё равно считает движок. Без речевых ключей доступен текст; заранее записанные звуки входят в проект. Внешний воркер не входит в репозиторий и для локальной проверки не нужен.

Docker — альтернативный запуск после настройки ворот в `.env`:

```sh
docker build -t peregovorka .
docker run --rm -p 8080:8080 --env-file .env -v peregovorka-data:/data peregovorka
```

Том `/data` сохраняет кэш, комнаты и учёт расходов. При обычном запуске они лежат в `CACHE_DIR` (по умолчанию `.cache`).

## Дела и возможности

В коде **10 исходных дел**, не считая жёстких версий и «Своего дела»:

| ID для `?case=` | Дело |
|---|---|
| `offer` | Оффер для робототехника |
| `tara` | Тара к запуску |
| `client` | Удержать клиента |
| `dorm` | Сосед по комнате |
| `stop` | Остановка у ларька |
| `shop` | Чайник без чека |
| `launch` | Ночь перед запуском |
| `istanbul` | The Istanbul Line — Стамбул, Эмре, разговор на английском |
| `china` | Поставщик из Шэньчжэня — Ли Вэй, разговор по-русски, допродажи |
| `lagos` | The Lagos Partnership — Лагос, Адебайо, разговор на английском |

Папка свободной игры и кабинет содержат 6 дел; ещё 4 бытовых открываются с карты сюжета и по ID. Семь глав «Новенького» объединяют три русскоязычных рабочих дела и четыре бытовых. Разбор и подсказки английских дел — по-русски. Суффикс `-hard` открывает более жёсткого собеседника, например `tara-hard`. «Своё дело» собирает сценарий и проверяет таблицы; без модели подбирает близкое дело из библиотеки.

Встреча идёт в 3D с запасным 2D-видом. При настроенном распознавании основной ввод — голос: микрофон слушает на вашем ходу, пауза отправляет фразу. Нужны разрешение браузера и HTTPS либо localhost. Текст включается в настройках или через `?text`. После встречи — выгода, доверие, карта сделок, разбор с цитатами и переигровка с выбранного хода.

В кабинете руководитель создаёт тренировку и получает две ссылки: участнику и на доску. Доска показывает ход встречи, попытки и CSV; переписка передаётся с согласия игрока. Секрет доски хранит руководитель: он открывает результаты группы. На закрытом сайте нужен также вход через ворота. Корпоративных аккаунтов и SSO пока нет.

## Как устроено

- React + Three.js — интерфейс, Hono + Node.js — API и статика. Движок `src/engine` считает уступки, доверие, очки и финал по таблицам сторон.
- Разметка — Claude Sonnet 5.5 через AITunnel → YandexGPT 5.1 Pro → офлайн-правила. Реплика — Sonnet → основная модель (в рекомендуемой настройке YandexGPT Pro) → заготовка. Сервер проверяет числа, согласие и раскрытие тайн.
- Короткий «заход» перед репликой Sonnet пишет YandexGPT Pro: отклик без условий и обязательств. Разметка и реплика могут готовиться параллельно; ранний текст Scribe позволяет готовить ход ещё во время паузы. Фиксированную задержку ответа не обещаем.
- Голос — ElevenLabs через воркер → SpeechKit. Живой синтез по умолчанию `eleven_v4_turbo`; у отдельных лиц заготовки используют `eleven_v3`, для живых ответов он включается через `ELEVEN_LIVE_V3=on`.
- Распознавание — Scribe при настроенном воркере; при отказе полная запись идёт в Яндекс с хеджем (до двух попыток). При `KIT=base` речь целиком обслуживает SpeechKit.
- Разбор отмечает 22 поведенческих индикатора с цитатами. Это учебная обратная связь; перенос навыка на реальные переговоры и пригодность для аттестации пока не доказаны.

## Доступ, голосование и лимиты

`?key=…` — общий или личный вход жюри: сервер выдаёт cookie и убирает ключ из адреса. `JURY_KEYS` — пары `имя:ключ` через запятую; битые записи пропускаются, при дубликатах остаётся первая корректная пара. Статистика входов — `/api/admin/jury` с отдельным `ADMIN_KEY` в `Authorization: Bearer …`.

Голосование за голоса персонажей — отдельная страница `/golosa/<VOTE_KEY>`; без `VOTE_KEY` выключена и доступ в игру не открывает. Итоги — `/golosa/<VOTE_KEY>/итоги`, отдельный `VOTE_ADMIN_KEY` вводится в форме. Ключи администратора в URL не передавайте; ранее переданные так ключи замените. Бланки хранятся в `CACHE_DIR/votes.json`.

Бюджет по умолчанию — 6000 расчётных рублей на модели и речь. С 80% Яндекс переходит на Lite там, где запрос не требует Pro; при исчерпании бюджета новые платные вызовы блокируются. Учёт внутренний, фактический счёт провайдера может отличаться. Квоты и таймауты — в `.env.example`. Ключи задаются через окружение, браузер их не получает; `.env` исключён из Git.

Исходный код доступен для чтения в `src/`, без обфускации. Зависимости зафиксированы в `package-lock.json`; устанавливайте через `npm ci`. Проверку таблиц всех дел запускает `node --import tsx scripts/check-scenarios.ts`.
