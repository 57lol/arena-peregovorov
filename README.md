# Переговорка

Игра-тренажёр переговоров для закупок, продаж и найма. Игрок договаривается с персонажем, получает разбор своих фраз и может переиграть трудный ход. Руководитель даёт команде одно дело по ссылке и видит результаты на общей доске.

Финал ЛЦТ 2026 · кейс №9 ОЭЗ «Алабуга». Ссылка на демонстрацию и ключ жюри — в материалах сдачи. `/?jury` открывает маршрут проверки: своё дело → встреча → разбор → кабинет. Сам параметр доступ на закрытый сайт не выдаёт.

## Браузер

Лучше всего игра работает в **Google Chrome**: в нём шла основная разработка и все автопрогоны (Playwright на Chromium). Чтобы повторить наш результат как можно точнее, проверяйте в Chrome на ноутбуке. Для голоса нужен доступ к микрофону и HTTPS или localhost.

| Место | Браузер | Как проверяли |
|---|---|---|
| 1 | Chrome (macOS, Windows, Android) | основной: ручные партии голосом и текстом, все сценарные проверки |
| 2 | Edge | тот же движок Chromium; отдельно не проверяли |
| 3 | Safari (iPhone, macOS) | партии на iPhone, вёрстка на 390 px в симуляторе iOS, вход по ссылке из Telegram |
| 4 | Firefox | ручные партии в браузере на движке Firefox; проверок меньше всего |

Если 3D-вид тормозит или WebGL недоступен, игра сама переходит на 2D-вид. Без микрофона можно играть текстом (`?text`).

## Как проверить без ключей

1. Установите Node.js **22.12 или новее в ветке 22** (или 24; 23 и 25 не подходят — их не поддерживает vitest из `package-lock.json`; проверено на 22.22) и зависимости: `npm ci`. Версии зафиксированы в `package-lock.json`; для первой установки нужен доступ к npm или заранее заполненный npm-кэш.
2. В чистой копии проекта без `.env` запустите `npm run dev:offline`. Ключи внешних сервисов не нужны.
3. Откройте `http://localhost:5173/?jury&text`, выберите дело, проведите встречу и откройте разбор. Без ключей работают правила и заготовки; микрофон и живой синтез недоступны.
4. Для проверки сборок и тестов выполните `npm run build`, `npm run build:server`, `npx vitest run`. Эти команды не поднимают игровой сервер.

Сценарные проверки интерфейса — `scripts/*-e2e.ts` и `scripts/regress-final.ts` (Playwright). Они идут против запущенного `npm run dev:offline`: `npx tsx scripts/qa-flow-e2e.ts`. Перед первым запуском скачайте браузер: `npx playwright install chromium`. Снимки пишутся в `~/Arena-materials/shots/`.

### Где в игре требования кейса

| Требование | Где смотреть (`/?jury&text`) |
|---|---|
| Настройка: сфера, тема, роль, тон, сложность, цели | шаг 1 «Настроить» → «Своё дело»: пять рабочих шаблонов (закупка, найм, аренда, продажа, подряд) или с нуля; поля — сфера, «О чём договариваемся», «Кто вы», характер собеседника, «Кто напротив», «Цель другой стороны», сложность, «Что хотите потренировать» и необязательная «Своя история» (до 1500 знаков); у готовых дел — кнопка «Жёстче» |
| Админ-контур | шаг 4 «Команда» или кнопка «Руководителю» на титуле — кабинет: «Дело → Проверьте встречу → Ссылка команде», выбор лица и места, доска результатов и CSV |
| Сценарий с ветвлением и вариантами финала | шаг 2 «Провести»: ход встречи зависит от уступок и доверия; у каждого дела 8 финалов, открытые видны на карте финалов в разборе |
| Обратная связь после раунда | подсказка после хода; шаг 3 «Разбор»: итог, цитаты, «в следующий раз», подробный разбор и переигровка с выбранного хода |
| Геймификация | личное дело и звания, звёзды и коллекция финалов, кампания «Новенький» из семи глав и карта недели |
| Мобильный сценарий | вся игра и доска — с телефона от 360 px; встреча в 3D с запасным 2D-видом |

Если `.env` уже настроен, `dev:offline` отключает только модели: для речи задайте `SPEECH=off`, а `KIT=base` уберите — он принудительно включает Яндекс. Офлайн-режим не требует интернета после установки зависимостей. Локальный API продолжает обслуживать кабинет и доску; без самого API остаётся только одиночная игра в браузере.

## Запуск и настройки

```sh
npm ci
npm run dev          # Vite :5173 + API :8787, для разработки
npm run dev:offline  # то же, модели отключены
npm run build        # TypeScript + фронт в dist/
npm run build:server # сервер в dist-server/server.mjs
npm start            # один production-сервер на :8787
```

Перед `npm start` задайте в окружении или `.env` **`GATE_SECRET`** и способ входа: `JURY_KEY`, `JURY_KEYS` либо пару `SITE_LOGIN` + `SITE_PASSWORD_HASH`. Без непустого `GATE_SECRET` production не стартует; один секрет подписи ещё не даёт пользователю способ войти. В режиме разработки ворота не подключены. `PORT` меняет порт API; при разработке передавайте его также процессу Vite.

[.env.example](.env.example) можно скопировать в `.env`. Там безопасный старт: `LLM_PROVIDER=offline`. Одного добавления ключей недостаточно, чтобы включить модели.

| Что включить | Переменные |
|---|---|
| Яндекс: модели и запасной путь | `LLM_PROVIDER=yandex`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` |
| Sonnet для разметки и реплик, Яндекс в запасе | Настройки Яндекса выше + `AITUNNEL_API_KEY`; модели по задачам выбираются автоматически |
| Только Яндекс для моделей, голоса и распознавания | `KIT=base` + ключ и folder ID Яндекса; отключает AITunnel, ElevenLabs и Scribe |
| Голос ElevenLabs через внешний воркер | `TTS_PROVIDER=elevenlabs`, `ELEVEN_RELAY_URL`, `ELEVEN_RELAY_SECRET`; ключ ElevenLabs хранится у воркера |
| Scribe Realtime | Тот же воркер; для публичного HTTPS-сайта за прокси задайте точный `STT_ORIGIN` |
| Отключить речь / отключить только Scribe | `SPEECH=off` / `STT_STREAM=off` (во втором случае остаётся Яндекс) |

Без ключей основной модели сервер переходит на правила. При сбое модели есть запасной путь, результат сделки всё равно считает движок. Без речевых ключей доступен текст; заранее записанные звуки входят в проект. Внешний воркер не входит в репозиторий и для локальной проверки не нужен.

### Внешние сервисы

Все необязательны: без любого из них игра переходит на запасной путь.

| Сервис | Зачем | Документация | Ключ | Переменные | Без него |
|---|---|---|---|---|---|
| YandexGPT (Yandex Cloud, Foundation Models) | основная модель, запасная разметка и реплика, «заход» | [yandex.cloud/ru/docs/foundation-models](https://yandex.cloud/ru/docs/foundation-models/) | API-ключ сервисного аккаунта в консоли Yandex Cloud + ID каталога | `LLM_PROVIDER=yandex`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `YANDEX_MODEL` | правила и заготовки |
| Yandex SpeechKit | синтез голоса и запасное распознавание | [yandex.cloud/ru/docs/speechkit](https://yandex.cloud/ru/docs/speechkit/) | тот же ключ Яндекса с правами на синтез и распознавание | `YANDEX_API_KEY`, `TTS_YANDEX_API` | текст и заранее записанные звуки |
| AITunnel | доступ к Claude Sonnet 5.5 для разметки и реплик | [aitunnel.ru](https://aitunnel.ru/) | личный кабинет AITunnel | `AITUNNEL_API_KEY`, `AITUNNEL_MODEL` | всё делает YandexGPT |
| ElevenLabs (синтез) | голоса персонажей | [elevenlabs.io/docs](https://elevenlabs.io/docs) | ключ хранится у внешнего воркера Cloudflare | `TTS_PROVIDER=elevenlabs`, `ELEVEN_RELAY_URL`, `ELEVEN_RELAY_SECRET` | SpeechKit |
| ElevenLabs Scribe | потоковое распознавание речи | [elevenlabs.io/docs](https://elevenlabs.io/docs) | тот же воркер | `ELEVEN_RELAY_URL`, `ELEVEN_RELAY_SECRET`, `STT_ORIGIN` | распознавание Яндекса |
| Anthropic API | Sonnet напрямую, необязательно | [docs.anthropic.com](https://docs.anthropic.com/) | ключ в console.anthropic.com, хранится у воркера | `ANTHROPIC_VIA_RELAY=on` + переменные воркера | AITunnel → YandexGPT |

Воркер Cloudflare — отдельная поставка, в репозитории его нет. Для локальной проверки он не нужен.

### Anthropic через воркер

Для кредита Anthropic оставьте `LLM_PROVIDER=yandex` и ключи Яндекса/AITunnel, добавьте `ANTHROPIC_VIA_RELAY=on`, `ELEVEN_RELAY_URL` и `ELEVEN_RELAY_SECRET`. Разметка (включая английские дела) и реплика пойдут по цепочке **Anthropic → AITunnel → YandexGPT → правила/заготовка**. Заход по-прежнему пишет YandexGPT. Для Anthropic параллельная быстрая разметка отключена: запасные вызываются после отказа основного. Без новых переменных прежний выбор сохраняется; `offline`, `main` и `KIT=base` сохраняют приоритет.

Явный выбор: `VOICE_LLM=anthropic:claude-sonnet-5-5`, `ANALYZE_LLM=anthropic:claude-sonnet-5-5`. Если эти переменные уже заданы для AITunnel, замените их или удалите для автоматического выбора. Альтернатива флагу и общей базе: `ANTHROPIC_BASE_URL=https://relay.example/anthropic/v1` (база **до** `/messages`). Секрет берётся из `ELEVEN_RELAY_SECRET` в обоих случаях.

Воркер должен принимать `POST <relay>/anthropic/v1/messages` с `x-relay-secret`, `anthropic-version: 2023-06-01`, `content-type: application/json`, проверять секрет и пересылать тело на `https://api.anthropic.com/v1/messages`, добавляя `x-api-key` из своих переменных. Возвращать исходные HTTP-статусы и тело; SSE передавать сразу, без буферизации, с отменой upstream при отключении клиента. Ключ Anthropic сервер игры не отправляет. Код воркера вне этого репозитория.

JSON обеспечивается инструкцией со схемой и assistant-префиллом `{`; транспорт возвращает скобку в начале потока, затем `content_block_delta/text_delta`. Это не строгая схема API: результат дополнительно проверяет игра. Незавершённый ответ, 429/529 и ошибки SSE запускают запасной путь. Системный промпт помечен `cache_control: ephemeral` (5 минут). Бюджет считает вход/выход и отдельные токены записи/чтения кэша; при обрыве недостающий usage оценивается. `ANTHROPIC_PRICE` — **предварительно** $3/$15 за миллион входных/выходных токенов, $3.75/$0.30 за запись/чтение кэша; **уточнить тариф Sonnet 5.5 до включения**. Перевод в рубли — `USD_RUB` (по умолчанию 100). Доступность модели, префилла и фактический тариф нужно проверить на воркере: локальные тесты работают без сети.

Docker — альтернативный запуск после настройки ворот в `.env`:

```sh
docker build -t peregovorka .
docker run --rm -p 8080:8080 --env-file .env -v peregovorka-data:/data peregovorka
```

Том `/data` сохраняет кэш, комнаты и учёт расходов. При обычном запуске они лежат в `CACHE_DIR` (по умолчанию `.cache`).

## Дела и возможности

В коде **10 исходных дел**, не считая жёстких версий и «Своего дела»:

| ID для `?case=` | Дело |
|---|---|
| `offer` | Оффер для робототехника |
| `tara` | Тара к запуску |
| `client` | Удержать клиента |
| `dorm` | Сосед по комнате |
| `stop` | Остановка у ларька |
| `shop` | Чайник без чека |
| `launch` | Ночь перед запуском |
| `istanbul` | The Istanbul Line — Стамбул, Эмре, разговор на английском |
| `china` | Поставщик из Шэньчжэня — Ли Вэй, разговор по-русски, допродажи |
| `lagos` | The Lagos Partnership — Лагос, Адебайо, разговор на английском |

Папка свободной игры и кабинет содержат 6 дел; ещё 4 бытовых открываются с карты сюжета и по ID. Семь глав «Новенького» объединяют три русскоязычных рабочих дела и четыре бытовых. Разбор и подсказки английских дел — по-русски. Суффикс `-hard` открывает более жёсткого собеседника, например `tara-hard`. «Своё дело» собирает сценарий и проверяет таблицы; без модели подбирает близкое дело из библиотеки.

Встреча идёт в 3D с запасным 2D-видом. При настроенном распознавании основной ввод — голос: микрофон слушает на вашем ходу, пауза отправляет фразу. Нужны разрешение браузера и HTTPS либо localhost. Текст включается в настройках или через `?text`. После встречи — выгода, доверие, карта сделок, разбор с цитатами и переигровка с выбранного хода.

Кабинет открывается кнопкой «Руководителю» на титуле. Три шага: «Дело» (шаблон, своё описание или готовое дело) → «Проверьте встречу» (собеседник, место, сложность, вводная и пункты торга; лицо выбирается из пула 14 лиц, показываются семь того же пола, место — на одно из шести деловых) → «Ссылка команде». Руководитель получает две ссылки: участнику и на доску. Доска показывает ход встречи, попытки и CSV; переписка передаётся с согласия игрока. Секрет доски хранит руководитель: он открывает результаты группы. На закрытом сайте нужен также вход через ворота. Корпоративных аккаунтов и SSO пока нет.

## Как устроено

- React + Three.js — интерфейс, Hono + Node.js — API и статика. Движок `src/engine` считает уступки, доверие, очки и финал по таблицам сторон.
- Разметка — Claude Sonnet 5.5 через AITunnel → YandexGPT 5.1 Pro → офлайн-правила. Реплика — Sonnet → основная модель (в рекомендуемой настройке YandexGPT Pro) → заготовка. Сервер проверяет числа, согласие и раскрытие тайн.
- Короткий «заход» перед репликой Sonnet пишет YandexGPT Pro: отклик без условий и обязательств. Разметка и реплика могут готовиться параллельно; ранний текст Scribe позволяет готовить ход ещё во время паузы. Фиксированную задержку ответа не обещаем.
- Голос — ElevenLabs через воркер → SpeechKit. Живой синтез по умолчанию `eleven_v4_turbo`; у отдельных лиц заготовки используют `eleven_v3`, для живых ответов — `ELEVEN_LIVE_V3=on` или единая модель `ELEVEN_LIVE_MODEL` (на проде `eleven_v3_conversational` у лиц с акцентом).
- Распознавание — Scribe при настроенном воркере; при отказе полная запись идёт в Яндекс с хеджем (до двух попыток). При `KIT=base` речь целиком обслуживает SpeechKit.
- Новичку перед первой встречей открывается «Как играть» — пять шагов с подсветкой настоящих кнопок; потом — из меню встречи.
- Разбор отмечает 30 поведенческих индикаторов с цитатами; у каждого — источник: глава одной из пяти книг по переговорам ([что мы взяли из книг](docs/research/books.md)) или исследование. Это учебная обратная связь; перенос навыка на реальные переговоры и пригодность для аттестации пока не доказаны.

## Доступ, голосование и лимиты

`?key=…` — общий или личный вход жюри: сервер выдаёт cookie, ключ остаётся в адресе (ссылка из Telegram открывается и после «Открыть в Safari»). `JURY_KEYS` — пары `имя:ключ` через запятую; битые записи пропускаются, при дубликатах остаётся первая корректная пара. Статистика входов — `/api/admin/jury` с отдельным `ADMIN_KEY` в `Authorization: Bearer …`.

Голосование за голоса персонажей — отдельная страница `/golosa/<VOTE_KEY>`; без `VOTE_KEY` выключена и доступ в игру не открывает. Итоги — `/golosa/<VOTE_KEY>/итоги`, отдельный `VOTE_ADMIN_KEY` вводится в форме. Ключи администратора в URL не передавайте; ранее переданные так ключи замените. Бланки хранятся в `CACHE_DIR/votes.json`.

Бюджет по умолчанию — 6000 расчётных рублей на модели и речь. С 80% Яндекс переходит на Lite там, где запрос не требует Pro; при исчерпании бюджета новые платные вызовы блокируются. Учёт внутренний, фактический счёт провайдера может отличаться. Квоты и таймауты — в `.env.example`. Ключи задаются через окружение, браузер их не получает; `.env` исключён из Git.

Исходный код доступен для чтения в `src/`, без обфускации. Зависимости зафиксированы в `package-lock.json`; устанавливайте через `npm ci`. Проверку таблиц всех дел запускает `node --import tsx scripts/check-scenarios.ts`.
