|---|---:|---:|

| Основной JS-чанк | 305,7 кБ | 101,2 кБ |

Скрипт считает entry и статические импорты без повторов. Один основной чанк не равен всему JS экрана. Эти числа описывают сборку; скорость сети, FPS устройств и задержку живого голоса здесь не измеряли.

## Что делает код

Кабинет, доска, карта, разбор, лаборатория, 3D и катсцены загружаются по требованию. 3D прогревается на брифе; музыка, фон и голосовые заготовки — для текущей сцены и собеседника.

Vite готовит `.gz` для JS, CSS и HTML. Сервер отдаёт их при поддержке gzip клиентом. Хэшированные ассеты кэшируются на год с `immutable`; MP3 — на 30 дней с `private`, HTML перепроверяется. API и потоки голоса этим сжатием не затрагиваются.

3D использует DPR 1 и адаптивное разрешение. При движении камеры и разговоре целевая частота — до 60 FPS, в покое и при reduced motion — до 30. В скрытой вкладке рендер приостанавливается. Если WebGL недоступен или производительность падает, игра переходит в запасной 2D-вид.

## Диагностика

`/?perf` или `/?jury&perf` показывает FPS интерфейса и 3D, размер буфера и время до первого коммита React (`UI готов`). Это приближение готовности интерфейса, не время ответа API и не Lighthouse. `heap` доступен только при поддержке `performance.memory` и не включает всю память GPU/аудио. Без `?perf` диагностический модуль не загружается.

Для живой проверки: холодная загрузка с мобильной сетью, слабое устройство, ширина 320/390 px, reduced motion, скрытие вкладки и несколько встреч подряд. Голос проверять отдельно: первый звук, отсутствие повторов, прерывание потока и освобождение микрофона при уходе. Сборка и тесты не заменяют эти проверки.
