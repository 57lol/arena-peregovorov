# Модели и речь: текущая схема

Сверено с кодом; внешние тарифы и доступность сервисов здесь не проверялись. Полная настройка — в [`.env.example`](../../.env.example), локальный запуск — в [README](../../README.md).

| Задача | Основной путь | При отказе |
|---|---|---|
| Разметка хода | Claude Sonnet 5.5 через AITunnel | YandexGPT 5.1 Pro, затем правила |
| Реплика собеседника | Claude Sonnet 5.5 через AITunnel | Основная модель, затем заготовка |
| Короткий «заход» | YandexGPT Pro | Безопасный короткий отклик или реплика без захода |
| Сборка своего дела | Основная модель | Близкое дело из библиотеки |
| Озвучка | ElevenLabs через внешний воркер | SpeechKit |
| Распознавание | Scribe Realtime через воркер | Полная запись → Яндекс с хеджем |

Эта схема включается при `LLM_PROVIDER=yandex`, ключах и folder ID Яндекса и `AITUNNEL_API_KEY`. Только ключ AITunnel при `LLM_PROVIDER=offline` модели не включает. Без переопределений Sonnet подключается отдельно для разметки и реплики; Яндекс остаётся основной моделью для запаса, генерации и захода. `ANALYZE_LLM=main` и `VOICE_LLM=main` возвращают соответствующую задачу основной модели.

`KIT=base` принудительно выбирает Яндекс для моделей и SpeechKit для речи, выключая AITunnel, ElevenLabs и Scribe даже при заданных ключах. Без ключей — правила и заготовки; `dev:offline` отключает модели, но речь выключается отдельно (`SPEECH=off`).

ElevenLabs нужно выбрать через `TTS_PROVIDER=elevenlabs`. Живые реплики по умолчанию используют `eleven_v4_turbo`; у Эмре, Ли Вэя и Адебайо заготовки используют `eleven_v3`. `ELEVEN_LIVE_V3=on` сохраняет v3 и для живых реплик этих лиц, `ELEVEN_OPENER_FAST=on` оставляет быстрый заход. Настройки конкретных голосов — `CAST`, `ELEVEN_TUNE` и `elevenBody` в `src/server/tts.ts`. Прямого OpenAI-голоса в игре нет.

Ранние текст и звук могут готовиться параллельно с разметкой, но сделку и очки определяет движок. Таймауты и кэш уменьшают ожидание; фиксированная задержка ответа не гарантируется. Подробнее — [распознавание](../stt.md).

Бюджет `LLM_TOTAL_RUB` по умолчанию — 6000 расчётных рублей. С 80% Яндекс использует Lite там, где допустимо; при исчерпании блокируются новые платные вызовы. AITunnel сообщает `usage.cost_rub`, остальные ставки заданы в коде. Цена полной встречи зависит от длины истории, кэша, повторов и речи; подтверждённого среднего чека в репозитории нет.
