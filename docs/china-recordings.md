# Ли Вэй: голос и записи

Дело `china` — «Поставщик из Шэньчжэня»: Ли Вэй торгует датчиками из шоурума «Хуамин Электроникс» у рынка Хуацянбэй. Разговор идёт по-русски; дополнительные товары включаются только с согласия игрока.

Голос в `CAST` (`src/server/tts.ts`) — `qEUg56UIsvkup7EM8Ovt`. У лица задан `eleven_v3`: он используется для заготовок, а живые ответы по умолчанию идут на `ELEVENLABS_MODEL` (`eleven_v4_turbo`). Чтобы живые ответы тоже шли на v3, задайте `ELEVEN_LIVE_V3=on`. При `ELEVEN_OPENER_FAST=on` заход остаётся на быстрой модели.

Акцент задаёт `src/server/zhAccent.ts`: меняется только текст для синтеза, на экране остаётся обычный русский. Числа предварительно превращаются в слова (`src/server/numWords.ts`). Эти правила применяются и к заготовкам, и к живым ответам ElevenLabs; название фирмы сохраняется. [Заметки об акценте](research/chinese-russian.md).

Список вступления, пауз, реакций, путей и тел запросов можно получить без обращения к API:

```sh
node --import tsx scripts/china-recordings.ts > china-recordings.json
```

Общий список заготовок: `node --import tsx scripts/eleven-known.ts list`. Реакции описаны в `scripts/reaction-voices.ts`. Подготовленные MP3 устанавливаются через `node --import tsx scripts/eleven-known.ts write picks.json`; формат элемента: `{ "id": "opening-china", "who": "china", "src": "/path/to/take.mp3" }`. Пути назначения — внутри `public/`. Синтез новых дублей требует ключей и расходует бюджет провайдера.

Портрет можно пересобрать командой `python3 tools/art/portraits.py china` (нужны Pillow и numpy). Готовая графика и записи уже входят в проект; для локального запуска пересобирать их не нужно.
