# Онбординг и понятные слова

Кому пишем: школьник или новичок, который пришёл в Алабугу, про переговоры не знает ничего и хочет весёлую игру. Ещё жюри: у них минута, чтобы понять, что происходит.

## Принципы

1. **Сначала действие, потом объяснение.** Duolingo даёт решить задание до регистрации, Celeste учит рывку ямой, которую без рывка не перепрыгнуть. У нас первое, что видит игрок, — собеседник и поле «ответить». Правила объясняем в момент, когда они понадобились.
2. **Один новый элемент за раз.** В первый день Papers, Please у инспектора один паспорт и одно правило, новые документы добавляют по одному. Первая встреча открывает интерфейс по шагам: разговор → блокнот → своё предложение → условия собеседника → «что он чувствует» → уйти.
3. **Каждый шаг — одна фраза и подсветка.** Наставник говорит одно предложение и показывает пальцем на кнопку. Кто уже понял, делает шаг сам, и наставник идёт дальше.
4. **Безопасное место для пробы.** Portal показывает новую механику в пустой камере, прежде чем совмещать её с другими. Первое дело самое мягкое: собеседница идёт навстречу, ошибки прощаются, любой ход отменяется.
5. **Покажи, а не расскажи.** Цифра «выгода» меняется, пока крутишь стрелки. Листок собеседника проезжает по столу. Так понятнее, чем абзацем в брифе.
6. **Не держать опытных.** «Я уже умею» на каждом шаге. Обучение идёт один раз, дальше интерфейс открыт сразу.
7. **Главное сверху, подробности по запросу.** В брифе четыре строки, в разборе три. Всё остальное свёрнуто для тех, кому интересно.

## Словарь

То, что видит игрок, пишем простыми словами. Термин можно оставить мелко в скобках там, где его ищут эксперты (подробный разбор, «Как мы считаем», доска руководителя).

| Было | Стало |
|---|---|
| положить на стол | предложить эти условия |
| принять | согласиться |
| запасной вариант, BATNA | если не договоритесь / без сделки у вас … |
| очки | выгода: насколько вам это выгодно (из 100) |
| рентген | что чувствует собеседник |
| осталось на столе, Парето | упущенная выгода: можно было лучше для обоих |
| размен | обмен: уступить в одном, чтобы получить другое |
| интересы собеседника | что для него важно и почему |
| протокол | запись разговора |

## Как устроено в коде

- `src/game/tutorial.ts`: шаги первой встречи, что на каком шаге видно, реплики наставника. Чистые функции, тесты рядом.
- `Play3D.tsx` прячет ещё не показанные бумаги и кнопки (`Desk.hidden` в `world3d/papers.ts`), подсвечивает нужную и вешает карточку наставника вместо плашек разбора хода.
- Обучение идёт в первой встрече, пока в прогрессе нет `tutorialDone`. Кнопка «Я уже умею» ставит флаг сразу. Сбросить: `localStorage.clear()`.
- Проверка «глазами новичка»: `npx tsx scripts/onboarding-e2e.ts`, снимки в `~/Arena-materials/shots/onboarding/`.
